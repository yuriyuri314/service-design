# 🏢 빈자리 태백 (Binjari Taebaek)

> **"계약 전에 따져보고, 혼자 말고 함께"**  
> 강원도 태백시 청년 빈집·유휴공간 창업 매칭 & AI 검토 플랫폼 모바일 앱

---

## 📌 1. 프로젝트 개요 및 배경

- **배경**: 강원도 태백시는 석탄 산업 합리화 이후 인구 감소와 초고령화(청년 20~39세 비율 **14.3%**, 65세 이상 고령화율 **32.7%**)를 겪고 있으며, 빈 공간과 지자체 창업 지원은 모두 존재하지만 서로 유기적으로 이어지지 않는 단절 문제가 있습니다.
- **핵심 문제**: 대부분의 지자체 창업 지원사업은 "공간을 먼저 확보한 사람"에게만 지원되지만, 정작 청년이 공간을 확보하는 단계(찾기·소유자 협의·수리비 산정·장기 운영 약속)를 돕는 지원책이 부재했습니다.
- **해결 방안 (3가지 핵심 질문)**:
  1. **판단**: 청년이 계약 전에 해당 공간을 쓸 수 있을지, 버틸 수 있을지 객관적 **AI 창업 검토 리포트**를 통해 사전에 진단합니다.
  2. **연결**: 검증된 리포트와 청년 프로필을 바탕으로 소유자와의 신뢰를 형성하고, **태백시 청년창창센터 전담 매니저가 동행 협의**합니다.
  3. **신청**: 확보된 공간 리포트 데이터를 공공 지원사업 양식으로 자동 변환하는 **AI 사업계획서**를 통해 지원사업 신청까지 한 흐름으로 이어갑니다.

## 📱 3. 화면 구성 및 핵심 기능

### 0. 스플래시 & 온보딩
- **스플래시**: 로고와 메인 슬로건 "계약 전에 따져보고, 혼자 말고 함께"
- **온보딩 3장 슬라이드**: 1. 판단 / 2. 연결 / 3. 신청 일러스트 소개
- **역할 선택**: "창업하려는 청년" vs "공간 소유자" (언제든 마이에서 전환 가능)
- **청년 관심 설정**: 희망 업종, 예산 범위, 태백 내 희망 동네 설정

### 1. 홈 탭
- 인사말 및 직방 스타일 와이드 검색창
- 카테고리 아이콘 그리드 (빈집 / 빈 상가 / 창고·공장 / 폐교·공공시설 / 전체)
- 내 창업 진행 미니 카드 (공간 찾기 → AI 검토 → 소유자 협의 → 지원 신청 → 창업)
- AI 검토 가능 추천 공간 가로 스크롤 카드 (찜 기능 탑재)
- 마감 임박 태백 청년 지원사업 (D-day 배지)
- 선배 창업가 인터뷰 이야기 (상세 모달: "공간 구할 때 어려웠던 점" 강조 박스)
- 숫자로 보는 태백 데이터 통계 카드 (14.3%, 32.7%, 328곳)

### 2. 공간 찾기 탭 (지도 + 바텀시트)
- **태백시 중심 인터랙티브 지도**: 태백산, 황지연못, 철암역, 장성시장 등 주요 랜드마크
- **직방 스타일 마커**: 임대료(월세/무상협의) 및 면적(평수) 핀 표시
- **상단 필터 칩**: 동네(황지동, 장성동, 철암동, 문곡소도동 등), 공간 유형, 보존 상태
- **3단계 바텀시트 리스트**: 접힘(92px) / 절반(380px) / 전체(650px) 스냅
- **공간 상세 모달**: 상단 사진 캐러셀, 스펙 그리드, 소유자 메시지 강조 박스, 추천 업종, 주변 거리, 하단 고정 CTA ("이 공간 AI로 검토하기" + 찜)

### 3. AI 검토 탭 (판단)
- 종합 판정 점수(88점) 및 신호등 위험도 배지
- 공간 진단: 노후 상태, 필요 수리 범위, 예상 수리비 및 숨은 비용(전기승압, 배관)
- 버틸 수 있을까?: 유동인구, 예상 월매출, 손익분기 시점 분석
- 태백 지역 자원(탄광 역사, 고원 기후) 연계 업종 추천
- 소유자 협의 요청 연결

### 4. 협의 탭 (연결)
- 상단 5단계 진행 바 (요청 → 소유자 확인 → 현장 방문 → 조건 협의 → 계약)
- 첫 메시지 AI 검토 리포트 & 청년 프로필 자동 첨부
- 태백시 청년창창센터 전담 매니저 동행 협의 배너
- 현장 방문 일정 잡기 및 실시간 메시지 대화

### 5. 내 창업 탭 (신청 + 마이)
- 단계형 창업 타임라인
- 공간 확보 단계 맞춤형 지원사업 카드
- AI 사업계획서 초안 에디터 (리포트 데이터를 바탕으로 공공 양식 자동 생성 및 저장)
- 찜한 공간 목록
- 소유자 모드 전환 스위치

### 6. 소유자 모드
- 방치 공간 관리 부담 감소, 검증된 사업계획 확인, 지원기관 동행 혜택 안내
- 유휴공간 신규 등록 폼
- 청년 협의 요청 수락/보류 관리

## 🚀 5. 로컬 실행 방법

### 1) 프로젝트 디렉토리 이동
```bash
cd /Users/gim-yul/.gemini/antigravity-ide/scratch/binjari-taebaek
```

### 2) 웹 브라우저에서 실행 (추천)
```bash
npm run web
# 또는
npx expo start --web
```
- 브라우저에서 `http://localhost:8081` 접속 시 iPhone 14 프레임 형태로 즉시 확인 가능합니다.
- 상단 바의 **"반응형 전체화면"** 버튼을 눌러 풀스크린 웹과 모바일 프레임 모드를 자유롭게 전환할 수 있습니다.

### 3) iOS / Android 모바일 디바이스에서 실행
```bash
# iOS 시뮬레이터
npm run ios

# Android 에뮬레이터
npm run android

# Expo Go 앱으로 QR코드 스캔
npm start
```
