# 🏢 빈자리 태백 (Binjari Taebaek)

> **"계약 전에 따져보고, 혼자 말고 함께"**  
> 강원도 태백시 청년 빈집·유휴공간 창업 매칭 & AI 검토 플랫폼 모바일 앱

---

## 📌 1. 프로젝트 개요 및 배경

- **배경**: 강원도 태백시는 석탄 산업 합리화 이후 인구 감소와 초고령화(청년 20~39세 비율 **14.3%**, 65세 이상 고령화율 **32.7%**)를 겪고 있으며, 빈 공간과 지자체 창업 지원은 모두 존재하지만 서로 유기적으로 이어지지 않는 단절 문제가 있습니다.
- **핵심 문제**: 대부분의 지자체 창업 지원사업은 "공간을 먼저 확보한 사람"에게만 지원되지만, 정작 청년이 공간을 확보하는 단계(찾기·소유자 협의·수리비 산정·장기 운영 약속)를 돕는 지원책이 부재했습니다.
- **앱을 이끄는 3가지 질문 (핵심 솔루션)**:
  1. **판단**: 청년이 계약 전에 해당 공간을 쓸 수 있을지, 버틸 수 있을지 객관적 **AI 창업 검토 리포트**를 통해 사전에 진단합니다.
  2. **연결**: 검증된 리포트와 청년 프로필을 바탕으로 소유자와의 신뢰를 형성하고, **태백시 청년창창센터 전담 매니저가 동행 협의**합니다.
  3. **신청**: 확보된 공간 리포트 데이터를 공공 지원사업 양식으로 자동 변환하는 **AI 사업계획서**를 통해 지원사업 신청까지 한 흐름으로 이어갑니다.

## 🚀 4. 전체 화면별 기능 구현 상세

### 0. 스플래시 & 온보딩
- 슬로건 *"계약 전에 따져보고, 혼자 말고 함께"*
- 3단계 슬라이드 (1. 판단 / 2. 연결 / 3. 신청)
- 역할 선택 ("창업하려는 청년" vs "공간 소유자")
- 청년 맞춤형 관심사 설정 (업종, 예산, 태백 내 희망 동네)

### 1. 홈 탭
- 와이드 검색창 (동네명 또는 업종 키워드 검색 시 지도 필터 연동)
- 직방 스타일 카테고리 그리드 (빈집 / 빈 상가 / 창고·공장 / 폐교·공공시설 / 전체)
- 내 창업 진행 미니 카드 (현재 단계 표시 및 '이어서 하기')
- 추천 공간 가로 스크롤 카드 (찜 기능 탑재)
- 마감 임박 지원사업 (D-day 배지)
- 선배 창업가 인터뷰 카드 및 상세 모달 ("공간 구할 때 어려웠던 점" 강조 박스)
- 숫자로 보는 태백 통계 카드 (14.3%, 32.7%, 328곳)

### 2. 공간 찾기 탭 (지도 + 바텀시트)
- 태백시 중심 인터랙티브 지도 (태백산, 황지연못, 철암역, 장성시장 등 주요 거점)
- 직방 스타일 임대료·면적 배지 마커 (터치 시 하이라이트)
- 가로 스크롤 필터 칩 (동네, 유형, 상태 등급)
- 3단계 바텀시트 리스트 (접힘 / 절반 / 전체)
- 공간 상세 모달 (사진 캐러셀, 스펙 그리드, 소유자 메시지 강조 박스, 하단 고정 CTA)

### 3. AI 검토 탭 (핵심, 판단)
- 3단계 입력 폼: ① 공간 선택(또는 직접 사진 업로드) → ② 업종 선택 → ③ 예산 범위
- 동적 문구가 바뀌는 실시간 AI 정밀 진단 로딩 애니메이션
- **AI 창업 검토 리포트**:
  - 종합 적합도 점수(88점) 및 신호등 위험도 배지
  - (1) 공간 진단: 노후 상태, 필요 수리 범위, 예상 수리비, **숨은 비용 체크리스트(배관/전기/용도변경)**
  - (2) 버틸 수 있을까?: 유동인구, 예상 월매출, **손익분기점(BEP) 시뮬레이션 바**, 중복 업종 주의 권고
  - (3) 태백 지역 자원 연계 겹치지 않는 추천 업종 3선 (탄광 문화 브루펍 등)
  - (4) **리모델링 예상 시뮬레이션: 전/후(Before & After) 비교 인터랙티브 슬라이더**
  - 하단 고정 CTA: "소유자에게 협의 요청하기", "공유", "PDF 저장"

### 4. 협의 탭 (연결)
- 협의 목록 및 대화방 전환
- 상단 5단계 진행 상태 바 (요청 → 소유자 확인 → 현장 방문 → 조건 협의 → 계약)
- 첫 메시지 자동 첨부: AI 검토 리포트 카드 + 청년 창업가 운영 약속 프로필
- **현장 방문 일정 잡기 팝업 모달** (일정 선택 후 채팅방 안내 전송)
- **청년창창센터 담당자 초대 버튼** (이수진 매니저 자동 참여 및 보조금 동행 안내)
- 청년 메시지 전송 시 소유자 실시간 화답 시뮬레이션

### 5. 내 창업 탭 (신청 + 마이)
- 창업 5단계 여정 타임라인 가이드
- 나의 창업 조건 기반 **AI 맞춤 지원사업 매칭 (D-day 배지)**
- **AI 사업계획서 자동 초안 생성기**: AI 리포트의 수리비·상권·BM 데이터를 공공 지원사업 표준 서식으로 자동 작성, 직접 편집 및 "초안 저장", "PDF 공모서류 받기", "청년창창센터 접수"
- 찜한 유휴공간 및 검토 리포트 보관함
- 소유자 모드 전환 스위치

### 6. 공간 소유자 모드
- 소유자 4개 탭: `홈`, `내 공간`, `협의 요청`, `마이`
- **유휴공간 4단계 등록 폼**: 사진 촬영·업로드, 동네 및 상세 위치, 면적 및 건물 상태 등급, 희망 임대 조건(초기 1~2년 무상임대 또는 월세)
- **도착한 협의 요청 관리**: 청년 프로필 및 첨부 리포트 검토 후 [협의 수락(채팅방 입장)] / [보류]
- 소유자가 얻는 3대 이점 안내 (방치 공간 관리 부담 감소, 검증된 사업계획 확인, 지원기관 현장 동행)

## 💻 5. 실행 방법

```bash
# 1. client 디렉토리로 이동
cd client

# 2. 의존성 설치 (필요시)
npm install

# 3. 웹 브라우저에서 실행
npm run web
# 또는
npx expo start --web
```
- 브라우저에서 `http://localhost:8081` 접속 시 iPhone 14 모바일 프레임 모드로 즉시 체험 가능합니다.
- 상단 바의 **"반응형 전체화면"** 버튼을 눌러 풀스크린 웹과 모바일 프레임 모드를 자유롭게 전환할 수 있습니다.
